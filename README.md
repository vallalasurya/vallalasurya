### 🤖 RAG AI Chatbot
<img src="https://img.shields.io/badge/Generative%20AI-0B1F3A?style=flat-square"/> <img src="https://img.shields.io/badge/RAG-0D47A1?style=flat-square"/> <img src="https://img.shields.io/badge/FAISS-1565C0?style=flat-square"/> <img src="https://img.shields.io/badge/Ollama-2196F3?style=flat-square"/>

> Retrieval-Augmented Generation chatbot that answers questions from documents using a local LLM.

```text
 📄 PDF Document
       ↓
 Text Extraction
       ↓
 Chunking
       ↓
 Embeddings (Sentence Transformers)
       ↓
 Vector Store (FAISS)
       ↓
 Relevant Chunk Retrieval
       ↓
 Local LLM (Ollama)
       ↓
 💬 Answer
```

**Tech:** Python · Sentence Transformers · FAISS · Ollama · Streamlit
